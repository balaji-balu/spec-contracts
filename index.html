The spec is the source of truth

An AI-native, spec-driven development platform. Agents generate code from the spec and feed what the code teaches back into it, with every step validated, evaluated and approved by a person.

View on GitHub Quickstart See one spec end to end

Not waterfall: a living spec

Nobody can fully specify a system before building it. The first spec is a hypothesis, design is discovered through implementation, and business needs keep changing (Fowler and Joshi; Joshi on DSLs and LLMs).

So the spec grows in small, reviewed steps and changes whenever the code or the business teaches something new. Every change is linted, traced and approved, and the code follows it.
