# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, assume good intent, welcome newcomers, and keep criticism about the work, not the person.

## Reporting

If someone's behaviour makes you uncomfortable, contact the maintainer privately at **CONDUCT_CONTACT_EMAIL**. Reports are kept confidential. The maintainer will review each report and respond, following the Contributor Covenant's enforcement guidelines.
